# CS471_Milestone_Checkpoint

This model was written to try and identify if an aircraft's type can be predicted based on how it flies.
The dataset for this model was primarily derived from the Colorado Spring's airport, pulling one day of data from adsb.lol 
and then splitting that dataset into both training and testing.
The main goal of this model is to see if a QDA model can be correctly trained on the data and then correctly identify whether the type of aircraft
It is trained using per-point flight features and its accuracy is evaluated using a confusion matrix.
